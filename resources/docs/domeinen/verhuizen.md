# Een domein verhuizen

## Naar een andere registrar verhuizen

1. Open je domein in het klantportaal en ga naar **Verhuizen**.
2. Bevestig je wachtwoord om de **verhuiscode** (EPP/authcode) te tonen.
3. Geef deze code aan je nieuwe registrar om de verhuizing te starten.

## Naar Servura verhuizen

Start een verhuizing via de domeinchecker op de website. Je hebt de verhuiscode van je huidige registrar nodig. Na betaling starten wij de verhuizing automatisch.

> Houder- of contactgegevens wijzigen? Dat kan via **Houdergegevens** bij je domein, of intern overdragen naar een ander Servura-account via de domeininstellingen.
